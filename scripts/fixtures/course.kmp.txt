#KMP

# CT Studio synthetic fixture KMP (P0-T03).
#
# Minimal but valid racing track: one start position, a four-point checkpoint loop
# whose first checkpoint is the lap counter, matching enemy and item routes, one
# respawn point, and stage info for a 3-lap race. No GOBJ entries, because objects
# would need files from the user's own game (AGENTS.md rule 7).
#
# Geometry matches the fixture .blend: a ring of radius 120 Blender units exported at
# scale 100, i.e. radius 12000 game units, centred on the origin, road half-width 1400.
#
# Compile with:
#   wkmpt encode scripts/fixtures/course.kmp.txt --dest <out>/course.kmp --overwrite
# Syntax reference: https://szs.wiimm.de/doc/kmp/syntax
